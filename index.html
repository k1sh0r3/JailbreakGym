    Honest limits

    • Heuristic judging isn't perfect. The judge looks for leaked secrets, refusal language, and attack-specific markers — not true understanding. Edge cases will be mis-scored; read the transcripts.
    • The attack set is curated, not exhaustive. 36 base attacks plus deterministic mutations cover common techniques, but attackers innovate. A high score is evidence of diligence, not proof of safety.
    • Scores don't transfer across models. A prompt that holds on one model may break on another. Re-run when you change providers or models.
    • Your API key never leaves this page except to the model provider you select. It is stored only in your browser's local storage.
